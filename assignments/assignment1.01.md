## Question 2: Web Components Match

### Match the Web Components

  -----------------------------------------------------------------------
  Component                        Description
  -------------------------------- --------------------------------------
  **HTML**                         Creates the structure and content of a
                                   webpage.

  **URL**                          The web address used to locate a
                                   webpage.

  **HTTP**                         The protocol that allows browsers and
                                   web servers to communicate.
  -----------------------------------------------------------------------

### Explanation

-   **HTML (HyperText Markup Language):** HTML is the foundation of
    every website. It is used to create and organize elements such as
    headings, text, images, and links.
-   **URL (Uniform Resource Locator):** A URL is the unique address of a
    webpage. It tells the browser where to find a website on the
    internet.
-   **HTTP (HyperText Transfer Protocol):** HTTP is the communication
    protocol that allows a web browser to request information from a web
    server and receive the webpage. Most websites now use **HTTPS**,
    which provides a secure connection.

### Example

If you type **https://www.google.com** into your browser:

-   **HTML** builds the Google webpage.
-   **URL** tells the browser where Google is located.
-   **HTTP/HTTPS** transfers the webpage from Google's server to your
    browser.

### Conclusion

**HTML creates the webpage, the URL identifies its location, and HTTP
enables communication between the browser and the server. Together, they
make it possible to access websites quickly and efficiently.**
