# Front-End, Back-End & Full-Stack Development

## 1. Role Mapping

**Website:** YouTube

When we use YouTube, two main parts work together:

- **Front-End:** Everything users see and interact with, such as the video player, search bar, buttons, comments, and menus.
- **Back-End:** Everything that works behind the scenes, including storing videos, managing user accounts, processing searches, and delivering videos to users.

### Summary

The front-end provides the user experience, while the back-end manages the data and services that make the website work efficiently.

---

## 2. Tech Stack Research

### Front-End – React

React is a popular framework used to build fast, interactive, and responsive user interfaces.

### Back-End – Node.js

Node.js is a powerful runtime used to process requests, manage databases, and handle server operations.

### Summary

React creates what users see, while Node.js powers what users don't see. Together, they build complete and reliable web applications.

---

## 3. Comparison of Front-End, Back-End, and Full-Stack Development

Front-end development focuses on creating the visual and interactive parts of a website using technologies like **HTML, CSS, JavaScript, and React**.

Back-end development manages the server, databases, and application logic using technologies such as **Node.js, Python, and MySQL**.

Full-stack development combines both front-end and back-end skills, allowing developers to build complete web applications from start to finish.
